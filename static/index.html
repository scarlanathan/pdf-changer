Glissez un PDF ici

ou

  • Cliquez sur n'importe quel élément pour le sélectionner, Suppr pour l'effacer.
  • Double-cliquez sur un texte pour le réécrire, ou dans le vide pour en ajouter un.
  • Glissez pour déplacer, tirez les poignées pour redimensionner, Alt+glisser pour dupliquer.
  • Collez (Ctrl+V) ou déposez une image directement sur la page.
  • PDF scanné ? Un clic sur « Rendre le texte modifiable » et il devient éditable.

Tout reste sur votre ordinateur : rien n'est envoyé sur Internet.
